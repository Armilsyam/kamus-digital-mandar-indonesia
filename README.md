## 🏛️ Latar Belakang & Landasan Ilmiah
Bahasa Mandar adalah salah satu bahasa daerah Austronesia yang kaya akan nilai historis, maritim, dan sastra lisan di Provinsi Sulawesi Barat. Namun, di era transformasi digital, generasi muda menghadapi ancaman kemunduran penutur bahasa daerah (*language endangerment*).

**KADIMA-ID** hadir menjawab tantangan ini dengan mendigitalisasi secara komprehensif naskah otoritatif setebal 548 halaman:  
📖 **Kamus Bahasa Mandar-Indonesia Edisi Revisi (2025)**  
*Diterbitkan oleh Balai Bahasa Provinsi Sulawesi Selatan, Kementerian Pendidikan Dasar dan Menengah.*  
*Tim Penulis: Sandra Safitri Hanan, Abdul Muthalib, Idham, Nurhayati, Haeruddin, Jerniati, Charmilasari, Lia Pertiwi.*

## 🚀 Fitur Unggulan & Inovasi Teknologi

### 1. 🔍 Leksikon Digital Dwi-Arah (4.443 Entri Lema Lengkap)
- **Pencarian Cerdas Instan (Mandar ⇄ Indonesia)** dengan penyorotan kata kunci (*highlighting*) dan pencarian menurut kata dasar (*root word grouping*).
- **Transliterasi Aksara Lontara Mandar** pada setiap entri lema sesuai kaidah ortografi baku.
- **Transkripsi Fonetik IPA Otomatis** dengan indikator bunyi alofonik intervokalik.
- **Filter Multi-Dimensi**: Filter abjad (A–W), 11 kategori tematik budaya, serta 10 kelas kata (nomina, verba, adjektiva, adverbia, partikel, numeralia, pronomina, ungkapan, peribahasa, kiasan).
- **Fitur Aksesibilitas**: Sintesis suara pengucapan asli (TTS), salin data, penyimpanan bookmark lokal, serta modal etimologi mendalam.

### 2. 🧪 Laboratorium Fonologi & Alofon Mandar Interaktif
- **Simulasi Alofonik Real-Time**:
  - `/b/` → `[w]` saat diapit dua vokal (misal: *tabe* diucapkan `[tawe]`)
  - `/d/` → `[dz]` / `[ð]` (seperti huruf zal ذ) saat intervokalik (misal: *madondong* diucapkan `[madzondzong]`)
  - `/g/` → `[gh]` / `[ɣ]` (seperti huruf ghain غ) saat intervokalik (misal: *pago* diucapkan `[pagho]`)
  - `/j/` → `[y]` saat intervokalik (misal: *kaja* diucapkan `[kaya]`)
  - Letup glotal `/q/` (hamzah `[ʔ]`) pada posisi tengah dan akhir kata (*anaq*, *saqbe*)
- **Kalkulator Asimilasi Morfofonemik (Tabel III Halaman 19)**:
  - Mensimulasikan peluluhan dan pembentukan gugus konsonan kembar (*geminate*):
    `mang-` + `pau` → **mappau**, `mang-` + `boyang` → **mamboyang**, `mang-` + `kande` → **makkande**.
- **Kaidah Tekanan Kata (Stres)**: Visualisasi pola ekasuku, dwisuku, trisuku, dan catursuku.

### 3. 📜 Mesin Transliterasi Aksara Lontara Mandar (Unicode U+1A00–U+1A1F)
- Transliterasi dua arah: **Latin ⇄ Aksara Lontara Mandar**.
- **Papan Ketik Virtual (Virtual Keyboard)** untuk penulisan langsung *ina surat* (konsonan dasar) dan *anaq surat* (sandhangan vokal: *tettiq riaseq*, *tettiq riawa*, *kecce/taling*).
- **Bedah Morfografis Suku Kata**: Penjelasan komponen huruf dan tanda baca per suku kata.

### 4. 🧬 Mesin Bedah Morfologi Mandar (Morphological Dissector)
- Penguraian kata kompleks Mandar secara otomatis:
  `[Awalan/Prefiks] + [Kata Dasar] + [Reduplikasi] + [Akhiran/Sufiks] + [Klitik]`
- Dilengkapi analisis komprehensif **Tabel IV Sistem Pronomina Persona Tiga Seri** (*Seri I Bentuk Bebas*, *Seri II Pelaku & Pemilik*, *Seri III Objek & Enklitik*).

### 5. ⛵ Ensiklopedia Budaya Maritim & Warisan Budaya Takbenda (WBTb)
- **Perahu Layar Sandeq**: Glosarium anatomi perahu tercepat tanpa mesin (*sombal tanjaq*, *pallayarang*, *baratan*, *tada/cadik*, *guling*, dll.) dan falsafah passombal.
- **Tenun Sutra Lipaq Saqbe**: Galeri motif geometris tradisional (*Sureq Salaka*, *Sureq Padhadhang*, *Sureq Balo Tappang*, *Sureq Marasa*, dll.) dan makna stratifikasi sosialnya.
- **Sastra Lisan Kalindaqdaq**: Koleksi pantun 4 baris berirama serta **Alat Uji Metrum Kalindaqdaq (Live Syllable Meter Checker)** untuk memvalidasi pola ketat suku kata `8 - 7 - 8 - 7`.
- **Tradisi Sayyang Pattudu**: Dokumentasi budaya ritual kuda menari memperingati khatam Al-Qur'an.
- **Gastronomi Warisan Pesisir**: Ensiklopedia kuliner *Jepa*, *Bau Peapi*, *Golla Kambu*, *Kue Tetu*, dan *Sambal Mandar*.

### 6. 🎮 Pojok Belajar & Gamifikasi Bahasa
- **Tantangan Kuis Cerdas (10 Soal Berbobot)**: Dilengkapi umpan balik ilmiah instan, sistem poin, efek selebrasi konfeti, serta gelar kehormatan budaya (*Passombal Pemula*, *Pabbicara Mandar*, hingga *Maraqdia Basa Mandar*).
- **Mode Flashcard Repetisi Berjarak (*Spaced Repetition*)**: Kartu bolak-balik interaktif untuk menghafal kosakata Mandar dengan audio pengucapan.

### 7. 🌐 Pusat Data Terbuka (Open Cultural Heritage API)
- Unduh gratis dataset digital leksikon lengkap dalam format **JSON** dan **CSV** untuk mendukung peneliti linguistik, tenaga pendidik, pegiat bahasa daerah, dan pengembang teknologi kecerdasan buatan (NLP/LLM).

## 💻 Panduan Menjalankan Secara Lokal

### Prasyarat
- Node.js versi 18 atau lebih baru
- npm, yarn, atau pnpm

### Langkah Instalasi
```bash
# 1. Kloning repositori
git clone https://github.com/mandarpodcast/kamus-digital-mandar-indonesia.git
cd kamus-digital-mandar-indonesia

# 2. Pasang dependensi
npm install

# 3. Jalankan server pengembangan lokal
npm run dev
```

Buka peramban di `http://localhost:3000` untuk menjelajahi aplikasi.

### Membangun Versi Produksi
```bash
npm run build
npm start
```
