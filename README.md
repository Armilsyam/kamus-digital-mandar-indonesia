## 🏛️ Latar Belakang & Landasan Ilmiah
Bahasa Mandar adalah salah satu bahasa daerah Austronesia yang kaya akan nilai historis, maritim, dan sastra lisan di Provinsi Sulawesi Barat. Namun, di era transformasi digital, generasi muda menghadapi ancaman kemunduran penutur bahasa daerah (*language endangerment*).

**KADIMA-ID** hadir menjawab tantangan ini dengan mendigitalisasi secara komprehensif naskah otoritatif setebal 548 halaman:  
📖 **Kamus Bahasa Mandar-Indonesia Edisi Revisi (2025)**  
*Diterbitkan oleh Balai Bahasa Provinsi Sulawesi Selatan, Kementerian Pendidikan Dasar dan Menengah.*

## 🚀 Fitur Unggulan & Inovasi Teknologi

### 1. 🌐 Kamus Multifungsi 3 Bahasa Sekaligus (Mandar • Indonesia • English)
- **4.443 Entri Lema Terverifikasi** yang disajikan dalam 3 bahasa secara tersinkronisasi:
  - **[MDR] Bahasa Mandar**: Lema + Aksara Lontara + Fonetik IPA + Contoh Tuturan
  - **[IDN] Bahasa Indonesia**: Kelas Kata (POS) + Definisi Bahasa Indonesia + Terjemahan
  - **[ENG] English**: English POS + English Meaning / Gloss + Contextual Usage
- **Pencarian Cerdas Lintas 3 Bahasa**: Pengguna dapat mencari dengan kata kunci Mandar (*sandeq*), Indonesia (*perahu*), maupun English (*boat*), dan sistem akan menampilkan hasil yang saling bertaut secara instan.

### 2. 🤖 Asisten AI Budaya "Kaka-AI"
- Asisten kecerdasan artifisial interaktif spesialis bahasa dan kebudayaan Mandar.
- Nama **"Kaka"** berakar dari gelar kehormatan *Tomakaka* (pemimpin adat luhur Mandar) dan sapaan keakraban penuh hormat.
- **Kemampuan Kaka-AI**:
  - Menjawab pertanyaan leksikografi, etimologi kata, dan peribahasa Mandar.
  - Menjelaskan aturan fonologi, alofon, dan asimilasi morfofonemik.
  - Membantu menerjemahkan kalimat antara Mandar, Indonesia, dan English.
  - Membedah dan menggubah puisi sastra lisan *Kalindaqdaq* dengan perhitungan suku kata 8-7-8-7.
  - **Audio Suara Kaka-AI**: Setiap jawaban Kaka-AI dapat didengarkan langsung dengan satu klik tombol suara!

### 3. 🎙️ Studio Pelafalan Suara & TTS Kalimat Panjang (Multi-Fungsi)
- Suara dalam kamus tidak hanya melafalkan satu kata, melainkan **mampu melafalkan frasa dan kalimat panjang utuh** baik dalam **Bahasa Mandar**, **Bahasa Indonesia**, maupun **English**.
- **Preprocessing Fonetik Mandar Alami**:
  - Transformasi alofon intervokalik otomatis: `/b/` → `[w]`, `/d/` → `[dz]`, `/g/` → `[gh]`, `/j/` → `[y]`.
  - Letup glotal `/q/` diubah menjadi jeda glotis mikro alami (’).
  - Penanganan konsonan kembar (*geminate*: `pp`, `tt`, `kk`, `ss`, `rr`, `ll`).
- Pengaturan kecepatan suara (*0.75x, 0.9x, 1.0x, 1.2x*), tombol putar/jeda/berhenti, serta visualisasi gelombang suara (*waveform animation*).

### 4. 🎨 Diagram Vektor & Ilustrasi Visual Budaya
- **Diagram Skematik Anatomi Perahu Sandeq**: Vektor interaktif yang menggambarkan *Sombal Tanjaq* (layar segitiga gunting), *Pallayarang* (tiang utama), *Baratan* (lengan cadik ganda), *Tada* (pelampung katir), *Guling* (kemudi samping), dan *Pacceko* (lambung perahu).
- **Galeri Visual Motif Lipaq Saqbe (Sureq)**: Representasi pola tenun geometris *Sureq Salaka*, *Sureq Padhadhang*, *Sureq Balo Tappang*, dan *Sureq Marasa*.
- **Visual Gastronomi & Tradisi**: Ilustrasi kuliner *Jepa*, *Bau Peapi*, *Golla Kambu*, *Kue Tetu*, serta tradisi *Sayyang Pattudu*.

### 5. 🧪 Laboratorium Fonologi & Alofon Mandar
- Simulator alofon intervokalik real-time dan kaidah stres kata (*ekasuku, dwisuku, trisuku, catursuku*).
- **Kalkulator Asimilasi Morfofonemik (Tabel III Halaman 19)**:
  `mang-` + `pau` → **mappau**, `mang-` + `boyang` → **mamboyang**, `mang-` + `dundu` → **mandundu**.

### 6. 📜 Mesin Transliterasi Aksara Lontara Mandar (Unicode U+1A00–U+1A1F)
- Transliterasi dua arah: **Latin ⇄ Aksara Lontara Mandar**.
- **Keyboard Virtual Lontara** (*ina surat* dan *anaq surat*).

### 7. 🧬 Mesin Bedah Morfologi Mandar
- Dekomposisi visual kata kompleks: `[Prefiks] + [Bentuk Dasar] + [Sufiks] + [Klitik]`.
- **Tabel Pronomina Persona Tiga Seri (Tabel IV)**: *Seri I (Bentuk Bebas)*, *Seri II (Pelaku/Genitif)*, *Seri III (Objek/Enklitik)*.

### 8. 🎮 Pojok Belajar & Kuis Gamifikasi
- **Kuis Cerdas 10 Soal Berbobot** dengan evaluasi ilmiah, efek konfeti, dan penganugerahan gelar budaya (*Passombal Pemula* s.d. *Maraqdia Basa Mandar*).
- **Flashcard Spaced Repetition** untuk menghafal kosakata.

## 💻 Panduan Menjalankan Secara Lokal

```bash
# 1. Kloning repositori
git clone https://github.com/mandarpodcast/kamus-digital-mandar-indonesia.git
cd kamus-digital-mandar-indonesia

# 2. Pasang dependensi
npm install

# 3. Jalankan server pengembangan lokal
npm run dev
```

Buka peramban di `http://localhost:3000` untuk menjelajahi platform.

## 🚀 Panduan Mendorong ke GitHub & Deploy Live

### 1. Push ke GitHub
```bash
# Login akun GitHub Anda
gh auth login

# Dorong seluruh berkas ke branch main
git push -u origin main
```

### 2. Deploy Otomatis ke GitHub Pages
Alur kerja `.github/workflows/deploy.yml` telah terpasang. Di pengaturan repositori GitHub Anda (**Settings** → **Pages** → **Source**), pilih **GitHub Actions**.

### 3. Deploy ke Vercel
```bash
npx vercel
```
